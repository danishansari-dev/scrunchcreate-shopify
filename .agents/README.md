## Global Complementary Skills

In addition to these workspace skills, the following global Shopify developer skills are available via the `shopify-plugin`:
- `shopify-liquid`: Shopify Liquid reference & standard syntax
- `shopify-use-shopify-cli`: Shopify CLI command references & store execution
- `shopify-custom-data`: Metafields & Metaobjects modeling
- `shopify-admin`: Shopify Admin GraphQL APIs
- `shopify-storefront-graphql`: Headless / Storefront API queries
