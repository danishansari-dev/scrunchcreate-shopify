# Scrunch & Create Logo Assets

Brand: Scrunch & Create
Tagline: Created to Make You Shine

## Core Brand Asset Overview

- **Primary Logo**: Main brand presentation for flagship presence, packaging headers, and primary promotional collateral.
- **Horizontal Logo**: Website headers, email signatures, navigation bars, and wide horizontal banners.
- **Icon Only**: Standalone S&C monogram with sparkle star for social media profiles, app icons, circular badges, and small square spaces.
- **Submark**: Concentric circular brand stamp for packaging seals, product stickers, hang tags, and secondary brand stamping.
- **Wordmark**: Clean typographic lockup for documents, stationery, invoices, and text-focused layouts.
- **Favicon**: Multi-resolution web browser icons and PWA manifest assets for web and mobile applications.

## File Format Selection Guide

| Format | File Extension | When to Use |
|---|---|---|
| **Vector SVG** | `.svg` | Websites, mobile apps, digital UI, and vector design tools (Figma, Illustrator). Infinitely scalable with zero pixelation. |
| **Print PDF** | `.pdf` | Commercial printing, packaging manufacturers, offset presses, screen printing, and laser engraving. True vector resolution. |
| **Transparent PNG** | `.png` | Social media posts, marketplace storefronts (Amazon, Etsy, Shopify), presentation slides, and office documents. Exported at high-resolution 2x retina size with transparent background. |
